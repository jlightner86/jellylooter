v4.0.0 November 2026 Major Release
  • New 🎨 Completely redesigned interface with two layouts: Clean Grid (default) and Dashboard
  • New 🖼️ Poster grid with quality badges (4K / 1080p / HDR / Dolby Vision), ratings, and the size of every movie or show
  • New ✅ Smarter "you already have it" check - matches IMDb, TMDB, TVDB, AniDB and other IDs plus title & year, so nothing syncs twice. Owned items hide the download button
  • New 📄 Real page navigation (Previous / Next / Page x of y / jump to page), 25-100 posters per page, and 3-8 posters per row
  • New 📁 Visual folder picker with breadcrumbs, subfolder tiles and "New Folder" when choosing where to save
  • New 📺 Shows always go into Season folders; specials are offered separately and saved in a "Specials" folder
  • New 🧩 Missing episodes: shows you own display "−N" when episodes are missing, and the show page offers "Download N missing" straight into your existing folder. Sync fills in missing episodes too
  • New 🟢 Shows display Continuing or Ended; for a show that's still airing, the download window asks whether Sonarr should watch for new episodes
  • New ⬅️ Browser Back / Forward move through JellyLooter (pages, shows, libraries, tabs)
  • New 🔄 Sync page with library mappings, "Sync Media" and "Sync Duplicate Media", plus a never-sync list (🚫 on any poster)
  • New 📚 Adding a server automatically finds and saves its library list
  • New 🏠 Local vs remote servers - your own server is browse-only, so you can't download your own media
  • New ⚙️ Settings split into General, Pro and Advanced tabs, with your license status at the top
  • New 🛠️ Advanced tab: live activity log, local library rescan, statistics reset, login, external API key, timezone and performance settings, license backup
  • New ✅ Every Test button (Jellyfin, TMDB, TVDB, OMDb, Sonarr, Radarr, Lidarr) shows the result on the button itself
  • New 📌 Download panel and library sidebar stay in place while you scroll; finished downloads get an instant ✓
  • New ⏹️ "Stop after current" really pauses the queue once running downloads finish
  • Pro ⚡ Multi-connection downloads - large files download in parallel parts (about 2x faster)
  • Pro 🔁 Crash-safe resume - each part resumes on its own after an outage, finished files are size-checked and verified with ffprobe, and the queue comes back automatically after a restart or power cut
  • Pro 📼 Download when a server blocks downloads - grabs the original-quality stream instead (same file, full speed). On/off switch in Settings → Pro
  • Pro 🛡️ Built-in WireGuard VPN - Proton, PIA (built-in login + region picker), Mullvad, IVPN, AirVPN, Windscribe, Surfshark or any WireGuard config, with an optional kill switch
  • Pro 📡 Sonarr / Radarr / Lidarr get the show, movie or artist the moment you click Download (monitored, no indexer search), with automatic path detection
  • Pro ⬆️ Better quality available: a blue ⬆ marks shows and movies the remote has in higher resolution; "Download & replace" swaps your copies only after each new file is verified
  • Pro 📈 Detailed download statistics - per day, type, server, hour and weekday, top shows, largest and fastest files. Open it from Download Analytics in the left sidebar of either layout
  • Pro 🎬 GPU transcoding on NVIDIA (NVENC), Intel QuickSync and AMD/Intel VAAPI, with download/bandwidth scheduling and per-server workers
  • Pro 🎉 Holiday themes
  • Pro ⏸️ Lowering download or transcode workers pauses the extra one mid-file and resumes it when a slot frees up
  • Improve 🚀 Downloads are dramatically faster - the license was being re-checked on every 64 KB chunk
  • Improve 🖼️ Posters load through JellyLooter, so they work even when your browser can't reach the remote server
  • Improve ⬆️ Upgrading from v3.x keeps every server, login, mapping and setting (a backup of the old config is saved)
  • Improve ✏️ Editing a server keeps its sync mappings; free plan allows 1 local + 2 remote servers
  • Improve 🌍 English, Spanish and German interface
  • Fix 🔑 Saved server keys could be encrypted twice (and stop working); servers with password logins now store their user ID
  • Fix 🔎 The local library scan used the first user on the server and could include remote servers - it now scans only your local server as your account
  • Fix 📡 Sonarr never received the show's IDs, so shows weren't added
  • Fix 📺 TVDB works without a subscriber PIN (only needed for subscriber keys)
  • Security 🔐 Server keys, VPN keys and passwords are never sent to the browser or included in config exports
  • Security 🔒 License backup endpoints now require login
  • New 🌟 New favicon matching the JellyLooter logo
