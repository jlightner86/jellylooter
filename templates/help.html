🚀 Getting Started

Add your servers in Settings → General. Your own Jellyfin is the Local server (where media ends up); friends' servers are Remote (where you download from). JellyLooter reads each server's library list as soon as you add it.
Pick a remote server in the left sidebar, then a library. Posters show quality, rating, size and a green ✓ for anything you already have.
Click ⬇ on a poster (or open a show and use "Download"). Choose the folder in the visual folder picker and start the download.
Want it automatic? Map a remote library to a folder on the Sync page and JellyLooter grabs anything new that you don't have.

🖼️ Browsing & Downloading

✅

Already have it?

A green ✓ means the movie or show is already on your local server, so its download button is hidden. ◐ means you have part of it. Matching uses IMDb, TMDB, TVDB and other IDs plus title and year, so the same show isn't downloaded twice.

🧩

Missing episodes

A show you own displays an amber −N when N episodes are missing. Open it and use Download N missing - they go straight into your existing show and season folders.

⬆️

Better quality available (Pro)

A blue ⬆ means the remote has a higher resolution than your copy (for example 1080p vs your 720p). Download & replace downloads the better files, checks each one, and only then removes your old copy through your Jellyfin. You're always asked first.

🟢

Continuing or ended

Shows display whether they're still airing. When you download a show that's still airing and Sonarr is connected, you're asked whether Sonarr should watch it for new episodes.

📄

Pages, poster size and sizes

Use Previous / Next or type a page number to jump. Change posters per row (3-8) and items per page in Settings → General → Browsing. The size under each poster is the whole movie or show.

📁

Choosing where it goes

The folder picker shows the subfolders of /storage as tiles - click to go in, use the breadcrumbs to go back, or make a New Folder. The folder you're looking at is where it's saved. Your sync mappings and last-used folder appear as quick picks.

📺

Seasons and specials

Episodes always go into Show/Season 01 style folders. If a show has specials, the download window asks whether you want them; they're saved in a Specials folder that Jellyfin and Sonarr recognise.

🏠

Your own server is browse-only

You can browse your local server, but you can't download from it - you already have that media.

⏹️

Download panel

The panel on the right shows active and queued downloads. ⏹️ finishes the current downloads and then pauses the queue, ⏸️/▶️ pause and resume, 🗑️ clears the queue (running downloads keep going).

🔄 Sync

🗺️

Library mappings

On the Sync page, pick a remote server, one of its libraries and a folder (for example /storage/anime). ✏️ changes the folder later.

▶️

Sync Media vs Sync Duplicate Media

Sync Media downloads anything in your mapped libraries that you don't already have - including the missing episodes of shows you own (turn this off with "Fill In Missing Episodes" in Settings). Sync Duplicate Media downloads everything, including items you already own (for example to replace them).

⏰

Automatic sync

Turn on Auto Sync and set the time in Settings → General. The free plan includes one mapping; Pro is unlimited.

🚫

Never sync something

Hover a poster and click 🚫. It's listed on the Sync page, where you can remove it again. You can still download it by hand.

🖥️ Servers

🔐

Username/password or API key

Either works. With a username and password, JellyLooter logs in once and stores the session token (not your password). Logins are encrypted on disk and never sent back to the browser.

✏️

Editing a server

Click ✏️, change what you need and Save. Leave the password blank to keep the current login. Sync mappings stay attached. 🔄 refreshes the server's library list.

🔢

How many servers

Free: 1 local and 2 remote servers. Pro: unlimited.

⚡ Advanced Downloading & Resume (Pro)

🚀

Multi-connection downloads

Files over 200 MB download in 2-8 parallel parts, usually about twice as fast. Set the number of connections in Settings → Pro.

🔁

Survives outages and restarts

Each part resumes exactly where it stopped after an internet drop. After a restart or power cut, unfinished and queued downloads come back automatically.

🔍

Verified files

Finished files are checked against the server's size and opened with ffprobe. A damaged file is downloaded once more automatically.

📼

Download when a server blocks downloads

Some servers turn off downloading. With this switch on, JellyLooter downloads the original-quality stream instead - the same file at full speed, no re-encoding. (Servers that also block playback can't be downloaded from.)

⏸️

Changing the number of downloads

Lower the download or transcode count while files are running and the extra one pauses mid-file, then continues when a slot frees up.

🛡️ VPN (Pro)

Send JellyLooter's internet traffic through WireGuard. Your home network (local Jellyfin, Sonarr/Radarr, this web page) stays direct.

🐳

One-time container setting

The container needs permission to create a network tunnel. Unraid: edit the container → Advanced View → Extra Parameters: --cap-add=NET_ADMIN. Docker Compose: add cap_add: [NET_ADMIN]. The VPN panel tells you if this is missing.

🔑

Proton, Mullvad, IVPN, AirVPN, Windscribe, Surfshark

Download a WireGuard configuration from your provider's website (the VPN panel shows where for each one), then paste or upload the .conf file.

🌐

Private Internet Access (PIA)

Enter your PIA username and password and pick a region - JellyLooter sets up WireGuard with PIA for you. Regions marked ⇄ support port forwarding.

🔒

Kill switch

On (recommended): if the VPN drops, all internet traffic is blocked and downloads wait until it reconnects - your real IP address stays hidden. Off: downloads continue without the VPN if it fails. Use Check My IP to confirm your address is hidden.

📡 Sonarr, Radarr & Lidarr (Pro)

🔑

Connect

In each app go to Settings → General → Security and copy the API Key. Enter the URL and key in Settings → Pro → *arr Integration and click Test.

🗂️

"How the *arr apps see /storage"

Your *arr apps usually see your media share under a different path (for example /data/media). Click Auto-detect and JellyLooter works it out from their root folders.

➕

What happens when you download

The moment you click Download, the show (Sonarr), movie (Radarr) or artist (Lidarr) is added - monitored, in the root folder that matches where you're saving, without an indexer search. When files finish, the app is told to import them. Folder names follow your *arr naming when it already has the title.

🎬 Transcoding (Pro)

🎛️

Presets

Original (no transcode), H.264, H.265/HEVC, Mobile (720p), 4K Optimized, AVI, or your own FFmpeg arguments. "Skip if larger" keeps the original when the result would be bigger.

🖥️

Using your GPU

NVIDIA: install the Nvidia-Driver plugin on Unraid, add --runtime=nvidia to Extra Parameters and set NVIDIA_VISIBLE_DEVICES=all and NVIDIA_DRIVER_CAPABILITIES=compute,video,utility, then choose NVIDIA NVENC as the encoder. Intel QuickSync / AMD: pass through /dev/dri and choose QuickSync or VAAPI.

💾

Cache drive and statistics

Optionally transcode on a fast cache drive first. The Pro tab shows how much space transcoding has saved, and can clear leftover cache files.

🔍 Metadata Keys

🗝️

TMDB, TVDB, OMDb

Optional free keys that help find missing IMDb/TVDB IDs for folder names and matching. Each has a Test button. TVDB needs a v4 key (it looks like xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx); old v2/v3 keys no longer work, and the subscriber PIN is only needed for subscriber keys. New OMDb keys must be activated from the email OMDb sends.

📁 Folder Naming

🏷️

Why add IDs?

IDs in folder names help Jellyfin, Sonarr and Radarr identify titles correctly - especially anime, foreign films and common names.

📋

Formats

Choose in Settings → General → Metadata:
Standard - Movie (2010)
With IDs (space) - Movie (2010) tt1234567
With IDs {braces} - Movie (2010) {imdb-tt1234567} {tmdb-12345}
With IDs [brackets] - Movie (2010) [imdb-tt1234567]
TMDB ID only / IMDB ID only

📊 Statistics & History

📜

History

The History tab lists finished downloads with size, server and time. Today's and total counts appear in the sidebar.

📈

Detailed statistics (Pro)

Click Download Analytics in the left sidebar (both layouts) for downloads per day, by type and server, busiest hours and weekdays, top shows and movies, and the largest and fastest files over 7 days to a year.

⬆️ Upgrading from v3.x

✅

Nothing to re-enter

On first start, v4 moves your servers, logins, sync mappings and settings into the new layout automatically. Your Pro license carries over. A copy of the old settings is saved as looter_config.json.v3-backup.json in your config folder.

🔌 External API

Control JellyLooter from NZB360, Organizr, Home Assistant and similar tools.

🔑

Getting a key

Go to Settings → Advanced → External API and click New Key. Copy it right away - it is shown only once.

📡

Using it

Send the key in a header: X-Api-Key: your_key (or ?apikey=your_key).
GET /api/v1/status - queue, speeds, disk
GET /api/v1/queue - current downloads
POST /api/v1/queue/add - add a download
POST /api/v1/queue/pause / resume
GET /api/v1/history - download history
GET /api/v1/docs - full documentation

🏥

Health check

/health (no login needed) returns version, uptime, queue and disk status - handy for Docker healthchecks and monitoring.

💾 Backup & Restore

📤

Export / Import

In Settings → Advanced. Exports hide your keys and passwords; importing keeps the keys you already have. Old v3 exports can be imported too.

🔑

License backup

Pro licenses are also backed up inside your library folders. After a reinstall, use Settings → Advanced → License Backup → Restore.

🔧 {{ t.get('troubleshooting', 'Troubleshooting') }}

🔐

"Server rejected the saved login"

The server's session for JellyLooter was removed or expired. Click ✏️ on the server, enter the password again and save.

✅

Things I own don't show a ✓

Rescan your local library in Settings → Advanced → Local Library Cache. It also runs automatically every night.

🐢

Slow downloads

Check the speed limit (Settings → General) and bandwidth schedule (Pro). Pro multi-connection downloads usually help a lot.

📡

Sonarr/Radarr don't import

Make sure "How the *arr apps see /storage" is set (use Auto-detect) and the *arr app can see the same media share.

🛡️

VPN won't connect

Check the panel for "needs NET_ADMIN". "No handshake" means the config or account was rejected - download a fresh config from your provider. With the kill switch on, downloads wait (and show "Waiting for VPN") until it reconnects.

📜

Anything else

Open Settings → Advanced → Activity Log, filter for the item, and include those lines when you open an issue on GitHub.

❓ Frequently Asked Questions

Q: What's the difference between a Ko-fi donation and a Pro license?
Donations are a thank-you only. A Pro license ($10, lifetime) unlocks every Pro feature and removes the banner.
Q: What does Pro include?
Unlimited servers and sync mappings, multi-connection downloads with crash-safe resume and verification, downloading when a server blocks downloads, the built-in VPN with kill switch, Sonarr/Radarr/Lidarr integration, GPU transcoding, scheduling, per-server downloads, notifications, detailed statistics and holiday themes.
Q: Can I use JellyLooter with Plex?
No - it works with Jellyfin and Emby servers.
Q: Are my passwords and keys safe?
Server tokens, *arr keys and VPN keys are encrypted on disk, never sent back to your browser, and left out of config exports.
Q: Can I download a whole show or season?
Yes - open the show or season and click its Download button, or use ⬇ on the show's poster. JellyLooter queues every episode into the right season folders.
Q: What happens if a download fails?
It's retried automatically (number of retries and delay are in Settings → General). Pro keeps the partial file so it can resume instead of starting over.
Q: My license key isn't working.
Enter the key exactly as Gumroad sent it, dashes included. If you reinstalled, try Settings → Advanced → License Backup → Restore. Still stuck? Open an issue on GitHub.
